初めてのホームページ公開

2026/10/24(土)

何をしたか

  • HTMLを使って、初めてのホームページを作成した。
  • GitHubにリポジトリを作成し、HTMLファイルを公開した。
  • GitHub Pagesを利用して、インターネット上からアクセスできるようにした。
  • PCとスマートフォンの両方から、ホームページが表示されることを確認した。

学んだこと

  • HTMLは、タグを使ってWebページの構造を記述する。
  • <head> にはページの情報を記述し、`` には画面に表示する内容を記述する。
  • <title> はブラウザのタブなどに表示され、`

    ` はページ本文の大見出しとして表示される。

  • <p> は段落を表し、文章を記述する際に使用する。
  • GitHub Pagesを利用すると、HTMLファイルをWebページとして公開できる。

上手くいかなかったこと/h2>
  • HTMLの記述では、タグの書き忘れや入力ミスがあった。
  • 開始タグと終了タグを正しく対応させることや、HTMLの基本構造を意識することが大切だと分かった。
